# 代理软件导入

视频教程：[Windows](https://www.bilibili.com/video/BV1Ua411t7Em) | [Mac OS](https://www.bilibili.com/video/BV14v411L7mG)

## 配置代理软件

您可以访问[此链接](https://github.com/Diving-Fish/maimaidx-prober/releases)来下载最新版本的代理工具，文件名为**maimaidx-prober-proxy-(os).exe**（os指您的操作系统）。

> 一般来说，使用 windows 系统的玩家都可以下载 windows-amd64.exe 后缀的文件。

请将代理工具复制到一个空文件夹中，然后双击或使用控制台运行。

初次运行时，代理软件发起证书安装请求，请您授予管理员权限（或者输入密码）完成证书安装。

![](/img/cert-install.png)

点击回车关闭上方窗口后，程序会继续运行，并自动打开浏览器，请在其中登录水鱼账号并同意授权。授权页上只会请求「上传成绩」这一项权限——代理软件不读取您的成绩，也不读取您的资料。

> 若浏览器没有自动打开，请把控制台中打印出的那条地址复制到浏览器里访问。
>
> 授权是在您本机完成的：程序会临时监听一个本地端口用于接收授权结果，页面显示「授权成功」后即可关闭浏览器回到程序。

授权完成后，凭据会保存在程序目录下的 `credentials.json` 中，之后每次运行都不必再授权一次。如果软件提示如下，则代表成功启动：

```
2026/04/27 13:15:35 INFO: 正在等待授权完成……
2026/04/27 13:15:35 INFO: 授权成功，凭据已保存到 C:\Users\DivingFish\SomePath\credentials.json
2026/04/27 13:15:35 INFO: 登录成功（水鱼账号授权（OAuth））
2026/04/27 13:15:35 INFO: 使用此软件则表示您同意共享您在微信公众号舞萌 DX、中二节奏中的数据。
2026/04/27 13:15:35 INFO: 您可以在微信客户端访问微信公众号舞萌 DX、中二节奏的个人信息主页进行分数导入，如需退出请直接关闭程序或按下 Ctrl + C
2026/04/27 13:15:35 INFO: 代理设置已自动修改
2026/04/27 13:15:35 INFO: 代理已开启到 127.0.0.1:8033
```

:::tip
需要换一个水鱼账号时，用 `-reauth` 参数启动代理软件即可重新授权：

```plain
maimaidx-prober-proxy-windows-amd64.exe -reauth
```

您也可以随时在 [水鱼账号的「已授权应用」页面](https://auth.diving-fish.com/apps) 中撤销对本程序的授权，撤销后代理软件将无法再上传成绩。
:::

:::note
`credentials.json` 中保存的凭据等同于「允许本程序上传您的成绩」，请不要分享给他人。若您从旧版本升级而来，`config.json` 里原有的成绩导入 Token 仍然可用，程序不会强制您重新授权。
:::

之后，填写`config.json`文件。使用记事本、Notepad++ 或 VS Code 等文本编辑器打开`config.json`，并将 [刚刚生成的成绩导入 Token](/docs/intro.md#完成设置并生成导入-token) 写入对应区域的引号中，类似这样：

```json
{"token": "802f48105e7dbdd3c107cae68fd5f0fa4a6966b15795fbc2bb812ffc07aae023e39910fd3d06e2b0998e24154c7bb5f2714c7c4639e6c1b97e612d771832803d"}
```

## 导入数据

默认情况下，代理工具将会自行更改您的系统代理。如果打开代理程序后提示

```
2025/11/06 17:51:12 WARN: 自动修改代理设置失败。请尝试手动修改代理。
```

请按照折叠的部分进行操作。

*您也可以直接在微信登录的时候设置代理服务器，地址 127.0.0.1，端口 8033。*

<details>

  <summary>点击展开</summary>

*以下为Windows 10 系统的代理服务器设置方法。如果您的系统是Windows 10以外的Windows系统（如Windows 7），您可以自行搜索相应系统的代理服务器设置方法。*

打开代理程序后，在 Windows 设置中搜索**代理服务器设置**，进入设置界面，将设置调整如下图所示，之后点击保存。

![](https://www.diving-fish.com/images/maimaidx-prober/3.png)

*如果您使用了其他的系统代理软件（ Shadowsocks、V2Ray 等），请将它们关闭或调整至直连模式再进行设置。*

</details>

*Linux 系统不支持自动修改代理，请自行查找代理修改方法。需要修改 HTTP/HTTPS 的代理，代理 URL 均为 127.0.0.1:8033。*

打开**电脑版微信**，进入**舞萌 | 中二**公众号，点击**我的记录**，选择**舞萌DX**或者**中二节奏**。如果您的代理设置无误，页面将如下图显示：

![](/img/import-maimai.png)

![](/img/import-chuni.png)

在导入完毕后，刷新查分器界面，即可看到最新的乐曲成绩。

如果您需要更新您的成绩数据，无需重新配置代理软件，只需启动之后再次打开**电脑版微信**，进入**舞萌 | 中二**公众号，点击**我的记录**，选择**舞萌DX**或者**中二节奏**即可。
